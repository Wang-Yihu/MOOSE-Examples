# MOOSE-Examples
对于稳态耦合，算例
# Eq 1: x = 0.5*y + 1
# Eq 2: y = 0.25*x + 1

很容易就解出：
y = 10/7 = 1.4285714285714285714285714285714 
x = 12/7 = 1.7142857142857142857142857142857

这种联立求解，就是全耦合

松耦合：
x[1] = 0.5*y[0] + 1
y[1] = 0.25*x[1] + 1

如果y[0] = 1
那么
x[1] = 0.5*1 + 1 = 1.5
y[1] = 0.25*1.5 + 1 = 1.375

误差太大了！

紧耦合：
# 初始值
x[0]  = 1
y[0]  = 1
yr[0] = y[0] = 1

# yr: y_transfer

# 第一轮：不做松弛，直接使用 yr[0]
x[1] = 0.5*yr[0] + 1 = 0.5*1 + 1 = 1.5
y[1] = 0.25*x[1] + 1 = 0.25*1.5 + 1= 1.375
1 Picard |R| = |x[1] - (0.5*y[1] + 1)| = |1.5 - (0.5*1.375 + 1)| = 0.1875

# 第二轮
yr[1] = 0.7*y[1] + 0.3*yr[0] = 0.7*1.375 + 0.3*1 = 1.2625
x[2] = 0.5*yr[1] + 1 = 0.5*1.2625 + 1 = 1.63125
y[2] = 0.25*x[2] + 1 = 0.25*1.63125 + 1 = 1.4078125
2 Picard |R| = |x[2] - (0.5*y[2] + 1)| = |1.63125 - (0.5*1.4078125 + 1)| = 0.07265625



# 第三轮
yr[2] = 0.7*y[2] + 0.3*yr[1] = 0.7*1.4078125 + 0.3*1.2625 = 1.36421875
x[3] = 0.5*yr[2] + 1 = 0.5*1.36421875 + 1 = 1.682109375
y[3] = 0.25*x[3] + 1 = 0.25*1.682109375 + 1 = 1.42052734375
3 Picard |R| = |x[3] - (0.5*y[3] + 1)| = |1.682109375 - (0.5*1.42052734375 + 1)| = 0.028154296875

对于瞬态耦合，算例
dx/dt = -2x + y
dy/dt = x - 2y

t = 0时，x = 2, y = 1
有理论解

理论解：
x(t) = 3/2*exp(-t) + 1/2*exp(-3t)
y(t) = 3/2*exp(-t) - 1/2*exp(-3t)

时间离散以隐式欧拉为例

全耦合（同一个方程组联立）：

(x[n+1] - x[n])/Delta_t = -2*x[n+1] + y[n+1]
(y[n+1] - y[n])/Delta_t =  x[n+1] - 2*y[n+1]

联立方程，求解：
x[n+1] = ( (1 + 2*Delta_t)/Delta_t * x[n] + y[n] ) / ( ((1+2*Delta_t)**2/Delta_t - Delta_t) )
y[n+1] = (  -(1 + 2*Delta_t)/Delta_t * y[n] - x[n]  )/(  (-2*Delta_t-1)*(1+2*Delta_t)/Delta_t + Delta_t  )



松耦合（不联立方程组，其中一个方程的耦合量用上一步代替）：

先解第一个方程
(x[n+1] - x[n])/Delta_t = -2*x[n+1] + y[n]
解得
x[n+1] = (1/Delta_t*x[n] + y[n])/(1/Delta_t + 2)

再解第二个方程
(y[n+1] - y[n])/Delta_t = x[n+1] - 2*y[n+1]
解得
y[n+1] = (x[n+1] + 1/Delta_t*y[n])/(1/Delta_t + 2)

紧耦合（同一个时间步将耦合量反复迭代）
rf为松弛因子

第一时间步

求解前
0 Picard |R| = |(x[0] - x[0])/Δt + 2*x[0] - y[0]|

Picard 0
(x[1,0] - x[0])/Δt = -2*x[1,0] + y[0]，解x[1,0]
(y[1,0] - y[0])/Δt = x[1,0] - 2*y[1,0]，解y[1,0]
1 Picard |R| = |(x[1,0] - x[0])/Δt + 2*x[1,0] - y[1,0]|
yr[1,0] = rf*y[1,0] + (1-rf)*y[0]

Picard 1
(x[1,1] - x[0])/Δt = -2*x[1,1] + yr[1,0]，解x[1,1]
(y[1,1] - y[0])/Δt = x[1,1] - 2*y[1,1]，解y[1,1]
2 Picard |R| = |(x[1,1] - x[0])/Δt + 2*x[1,1] - y[1,1]|
yr[1,1] = rf*y[1,1] + (1-rf)*yr[1,0]

Picard 2
(x[1,2] - x[0])/Δt = -2*x[1,2] + yr[1,1]，解x[1,2]
(y[1,2] - y[0])/Δt = x[1,2] - 2*y[1,2]，解y[1,2]
3 Picard |R| = |(x[1,2] - x[0])/Δt + 2*x[1,2] - y[1,2]|
yr[1,2] = rf*y[1,2] + (1-rf)*yr[1,1]

第一时间步结束
x[1] = x[1,2]
y[1] = y[1,2]

第二时间步

求解前
0 Picard |R| = |(x[1] - x[1])/Δt + 2*x[1] - y[1]|

Picard 0
(x[2,0] - x[1])/Δt = -2*x[2,0] + y[1]，解x[2,0]
(y[2,0] - y[1])/Δt = x[2,0] - 2*y[2,0]，解y[2,0]
1 Picard |R| = |(x[2,0] - x[1])/Δt + 2*x[2,0] - y[2,0]|
yr[2,0] = rf*y[2,0] + (1-rf)*y[1]

Picard 1
(x[2,1] - x[1])/Δt = -2*x[2,1] + yr[2,0]，解x[2,1]
(y[2,1] - y[1])/Δt = x[2,1] - 2*y[2,1]，解y[2,1]
2 Picard |R| = |(x[2,1] - x[1])/Δt + 2*x[2,1] - y[2,1]|
yr[2,1] = rf*y[2,1] + (1-rf)*yr[2,0]

Picard 2
(x[2,2] - x[1])/Δt = -2*x[2,2] + yr[2,1]，解x[2,2]
(y[2,2] - y[1])/Δt = x[2,2] - 2*y[2,2]，解y[2,2]
3 Picard |R| = |(x[2,2] - x[1])/Δt + 2*x[2,2] - y[2,2]|
yr[2,2] = rf*y[2,2] + (1-rf)*yr[2,1]

第二时间步结束
x[2] = x[2,2]
y[2] = y[2,2]
