# MOOSE-Examples
对于稳态耦合，算例
# Eq 1: x = 0.5*y + 1
# Eq 2: y = 0.25*x + 1

很容易就解出：
y = 10/7 = 1.4285714285714285714285714285714 
x = 12/7 = 1.7142857142857142857142857142857

这种联立求解，就是全耦合

松耦合：
x[1] = 0.5*y[0] + 1
y[1] = 0.25*x[1] + 1

如果y[0] = 1
那么
x[1] = 0.5*1 + 1 = 1.5
y[1] = 0.25*1.5 + 1 = 1.375

误差太大了！

紧耦合：
# 初始值
x[0]  = 1
y[0]  = 1
yr[0] = y[0] = 1

# yr: y_transfer

# 第一轮：不做松弛，直接使用 yr[0]
x[1] = 0.5*yr[0] + 1 = 0.5*1 + 1 = 1.5
y[1] = 0.25*x[1] + 1 = 0.25*1.5 + 1= 1.375
1 Picard |R| = |x[1] - (0.5*y[1] + 1)| = |1.5 - (0.5*1.375 + 1)| = 0.1875

# 第二轮
yr[1] = 0.7*y[1] + 0.3*yr[0] = 0.7*1.375 + 0.3*1 = 1.2625
x[2] = 0.5*yr[1] + 1 = 0.5*1.2625 + 1 = 1.63125
y[2] = 0.25*x[2] + 1 = 0.25*1.63125 + 1 = 1.4078125
2 Picard |R| = |x[2] - (0.5*y[2] + 1)| = |1.63125 - (0.5*1.4078125 + 1)| = 0.07265625

# 第三轮
yr[2] = 0.7*y[2] + 0.3*yr[1] = 0.7*1.4078125 + 0.3*1.2625 = 1.36421875
x[3] = 0.5*yr[2] + 1 = 0.5*1.36421875 + 1 = 1.682109375
y[3] = 0.25*x[3] + 1 = 0.25*1.682109375 + 1 = 1.42052734375
3 Picard |R| = |x[3] - (0.5*y[3] + 1)| = |1.682109375 - (0.5*1.42052734375 + 1)| = 0.028154296875
